Moral Spectrum Analyzer · verification demo

Content is scored across ten moral axes by separately validated encoders, contracted to a decision, and bound to a hash-chained proof. The proof is re-verified in your browser, by a second implementation that shares no code with the analyzer.

4 · Invariance — the same meaning, re-described

Every variant below is a meaning-preserving re-description of the same scenario, scored independently. A moderation layer that changes its mind under paraphrase is not measuring content.
These are RAW per-item decisions, with the invariance mechanism off. That is the baseline, and it is the weak case: across this corpus the decision survives re-description in four of the eight scenarios that have variants, and changes in four. The mechanism that addresses it, averaging perception over a generated equivalence class, is measured separately on held-out items and roughly halves reframe drift, θd 0.407 → 0.219 against a pre-registered bar of 0.5 (docs/INVARIANCE_FINDINGS.md). It is not applied here, so what you see is the harder number, not the better one.

5 · Moral residue

Residue is what the decision did not resolve: axes still carrying material signal after the action was chosen. It is reported, not discharged.

What this demo does not claim

    

      Backend is cached: every number replays a real encoder run recorded on the
      GPU host. Text with no recorded run is refused rather than scored by a stub, because a stub
      number presented as a real one is the failure this project exists to avoid.

      Nine of ten axes are validated. rights_respect failed its pre-registered
      gate twice, including on a legal corpus, so it carries no validated graded feeder and is used
      only as a hand-specified deontic hard channel. It is shown failing.

      The corpus is a design set, not a benchmark. It demonstrates the mechanism and the audit
      path. It does not measure generalisation, and one item
      (harsh_but_factual_criticism) is a disclosed false positive kept in the record.
