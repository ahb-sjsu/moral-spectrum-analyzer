\chapter{The strata catalogue}\label{app:strata}

This appendix lists every stratification of Margaret's home as the scene file declares it. Each table
gives the states, the initial state, the authority states, the absorbing states, and every gate with
its identifier, trigger event, source states, target state and boundary type. The entries are copied
from \code{extra.strata} in \code{twin/scene/margaret\_home.erisml}. A trigger written as
\code{event=content} fires only on an event of that type with that content. A gate with no source
states fires from any state of its stratification. Chapter~\ref{ch:containment} explains what each
stratification changes.
% src: twin/scene/margaret_home.erisml:815-922
% src: C:/source/erisml-compiler-monitor/src/erisml_compiler/runtime/strata.py:21 (any stratum when `from` is omitted)

The scene runtime checks two rules when the scene loads. Only a system event may enter an authority
state, and only a human-oversight event may leave an absorbing state. The scene's oversight events
are \code{monitoring\_center\_confirmed\_privacy\_restore}, \code{visitor\_cleared},
\code{evidence\_lapsed} and \code{device\_cleared}. Across the seven stratifications there are 26
states and 34 gates.
